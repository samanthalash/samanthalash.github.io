# Portfolio Rebuild

The root site is a new portfolio for Samantha Lash. Its content and visual
hierarchy come from `references/goal-mockups/`; its desktop Home interaction uses
Constanza Coscia's fixed-left, scrolling-right portfolio as inspiration.

The first release contains Home, Projects, About, Hunter, Levi's, APRAMP,
Tomorrowland, and La Manuela. Beth Ellen and Anonymous Pro are the approved fonts.
All supplied wording must remain exact unless the user requests editing.
